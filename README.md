# RAW-Swiggy-Data-Analysis

# 🍽️ Swiggy Restaurant Data Analysis & Intelligence Dashboard

An end-to-end data analysis project exploring restaurant trends, delivery performance, pricing distributions, and customer ratings across major metro cities using **Python**, **SQL**, and an **Interactive HTML Dashboard**.

---

## 📌 Project Overview

This repository contains the complete workflow for analyzing Swiggy restaurant data, from raw data extraction and preprocessing to advanced SQL querying and dashboard visualization:

* **Data Cleaning & Exploration:** Processed and validated 8,680+ restaurant records using **Python (Pandas, NumPy)**.
* **Exploratory Data Analysis (EDA):** Visualized price distributions, rating densities, and delivery patterns with **Matplotlib & Seaborn**.
* **Database Querying & Insights:** Executed analytical queries and window functions using **MySQL**.
* **Interactive Dashboard:** Built a responsive, Swiggy-themed analytics dashboard using **HTML5, CSS3, and Chart.js**.
